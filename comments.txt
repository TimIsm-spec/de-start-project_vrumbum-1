car_shop



Дальше идут простые таблицы такие как countries  и colors.

У всех таблиц должен быть автоинкремент для уникальных идентификаторов

Используем универсальный тип данных VARCHAR для столбцов, в скобках

ограничиваем размер. 

Создаем ограничение с помощью  UNIQUE на  уникальные названия цвета.

Исключаем NULL



Таблица brands

Обязательный  автоинкремент, название столбца используем универсальный тип 

VARCHAR, исключаем NUll, и исключаем повторы  с помощью UNIQUE, создаем связь

с таблицей countries все связи идут по типу INTEGER, идем из общего к частному, последовательность страна- бренд-марка

Схема данных организована по нисходящему принципу



Таблица  models

Обязательный  автоинкремент, название столбца используем универсальный тип 

VARCHAR,исключаем NUll, создаем связь с таблицей brands, gasoline_consumption

является уникальной характеристикой модели поэтому создаем столбец в этой

таблице, создаем по типу NUMERIC(4,1) т.к. значения передаются в цифровом варианте

ограничиваю значение только на положительные CHECK (gasoline_consumption > 0),

с NOT NULL код не проходит поэтому его нет,  из сырой таблицы передаются строковые

значения 'null', которые перевожу в NULL. И создаем уникальную связь бренд и модель

Модель с разными брендами возможна, бренд с одинаковыми нет



Таблица customers

Обязательный  автоинкремент, название 2 столбцов используем универсальный тип 

VARCHAR. Посчитал что телефона может не быть поэтому нет NOT NULL



-- Таблица cars

обьединяем модель и цвет как уникальную характеристику для продаж авто

Обязательный  автоинкремент, создаем связи с таблицей models и с таблицей

colors. Создаю проверку NOT NULL для связей



Таблица sales

Обязательный  автоинкремент. Создаю связи с двумя таблицами cars  и customers.

Обязательная проверка  NOT NULL . Создаю столцбы price по типу NUMERIC(10,2),

 тип данных взят из примера в задании, обязательная проверка  NOT NULL и проверка

на значение выше 0. Дальше столбец даты sale_date, тип данных DATE -причина передача только

год, месяц, день, обязательная проверка  NOT NULL и столбец скидок discount по типу INT - только целые числа,

обязательная проверка  NOT NULL и проверка значений процентов от 0 до 100
